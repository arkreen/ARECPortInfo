### Codegen
`yarn codegen`

### Build
`yarn build`

### Authenticate

`graph auth --product hosted-service {key}`

`npx graph auth --product hosted-service 4620d..` 

`npx graph auth --product hosted-service gho_CKdr0...`


### Deploy

`npx graph deploy --product hosted-service lu-derik/arec-port`      (Deprecated)

For Celo Test Net:
`npx graph deploy --product hosted-service lu-derik/arec-port-celo` (Deprecated)

For Polygon Mummai Testnet:
`npx graph deploy --product hosted-service lu-derik/arec-port`      (Deprecated)

For Polygon Mainnet:
`npx graph deploy --product hosted-service lu-derik/arec-port-matic`  (Deprecated)
`npx graph deploy --studio arec-port-celo`
